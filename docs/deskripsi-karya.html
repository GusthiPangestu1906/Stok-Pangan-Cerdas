Deskripsi Singkat

Koperasi dan UMKM pangan sering merugi karena sayur, buah, olahan susu, dan roti terlambat diketahui mendekati kadaluarsa, sehingga terbuang alih-alih diselamatkan.

Stok Pangan Cerdas menjawabnya dengan dua lapis. Pertama, deteksi risiko rule-based yang menghitung sisa umur simpan setiap barang secara real-time dari tanggal masuk dan estimasi umur simpan, lalu menandainya Aman, Berisiko, atau Kritis dengan kode warna. Kedua, AI Insight Panel bertenaga Gemini API yang memberi rekomendasi tindakan konkret berbahasa Indonesia untuk barang berisiko: diskon, distribusi, bundling, atau pemusnahan bila sudah kadaluarsa.

Aplikasi dibangun dari nol: backend Laravel sebagai REST API murni, frontend Vanilla JavaScript dan Tailwind CSS, database PostgreSQL, autentikasi token Sanctum. Admin dapat mengelola stok, meminta saran AI, menandai tindakan yang diterapkan, lalu melihat rekapnya di halaman Riwayat beserta statistik barang terselamatkan.

Keandalan dijaga lewat retry otomatis dan rantai model cadangan saat layanan AI terganggu atau kuota habis.
